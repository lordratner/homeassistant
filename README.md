# homeassistant
Scripts, Blueprints, and more

## Sunrise Alarm with Music

[Sunrise Alarm with Music](blueprints/room_sunrise_alarm.md) is a
script blueprint: one restartable script per room, a 1/5/10-minute call-time
lead-in, and room-editor settings for devices, music and all light/audio levels.
Existing live alarms and callers have not been migrated.
